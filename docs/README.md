# Tài liệu thiết kế

Chép từ thư mục thiết kế gốc `wedding_invitation/` (80 MB, không đưa vào Git —
phần lớn là ảnh chụp các bản dựng thử và tài liệu tham khảo).

| Tệp | Nội dung |
|---|---|
| `font_map.md` | Từng dòng chữ trên thiệp dùng font nào, cỡ bao nhiêu, CSS nào chi phối |
| `asset_checklist.md` | Danh sách ảnh nguồn cần có và yêu cầu kỹ thuật từng cái |
| `TWEAK_GUIDE.md` | Bảng chỉnh tham số trực tiếp trên trình duyệt (`?tweak=1`) |
| `original-build.py` | Script dựng ban đầu, nhúng mọi thứ vào một tệp HTML |

## Hai việc về bản quyền cần xử lý trước khi gửi thiệp

`asset_checklist.md` ghi rõ: **font New Icon Script lấy từ Canva, cần mua trên
Creative Fabrica trước khi phát hành.** Thiệp đã chạy công khai nên việc này
đang quá hạn.

Nhạc nền là **Queen — Love Of My Life** tải từ NhacCuaTui. Dùng cho thiệp riêng
thì thực tế không ai hỏi, nhưng nó đang nằm trong repo GitHub công khai.
